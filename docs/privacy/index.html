Política de Privacidade — Maré

Última atualização: 25 de julho de 2026

A Maré é um diário de surf pessoal. Esta política explica, de forma direta, que dados a app usa e o que fazemos com eles.

Não existe conta nem servidor

A Maré não tem sistema de login, conta de utilizador, nem backend próprio. Todos os dados que registas — sessões, spots, pranchas, notas — são guardados exclusivamente no armazenamento local do teu dispositivo (base de dados SQLite dentro da app). Nunca enviamos esses dados para nós nem para terceiros. Se desinstalares a app, esses dados desaparecem contigo.

Localização

A Maré pede acesso à tua localização apenas quando tocas explicitamente no botão "Usar a minha localização" ao criar ou editar um spot. Esse acesso serve unicamente para preencher automaticamente as coordenadas desse spot. A localização não é recolhida em segundo plano, não é guardada em nenhum servidor, e não é partilhada com ninguém.

Dados meteorológicos e de mar

Para mostrar as condições do mar (ondulação, vento, maré) associadas a cada sessão, a Maré envia as coordenadas do spot e a hora da sessão ao serviço externo Open-Meteo, que devolve dados públicos de previsão/histórico marítimo. Não enviamos identificadores pessoais nesse pedido — apenas coordenadas geográficas e um timestamp.

Partilha de sessões

Se usares a funcionalidade "Partilhar" para gerar uma imagem de uma sessão, essa imagem é criada localmente no teu dispositivo e só é enviada para onde tu escolheres partilhá-la (ex: WhatsApp, Instagram) através do sistema de partilha nativo do telemóvel. Nós não temos acesso a essa imagem nem sabemos com quem a partilhaste.

O que a Maré não faz

  • Não cria conta nem perfil de utilizador
  • Não tem analytics, tracking publicitário, nem SDKs de terceiros para publicidade
  • Não vende nem partilha dados com terceiros
  • Não sincroniza dados na cloud (ainda)

Alterações a esta política

Se a Maré vier a introduzir funcionalidades que mudem este comportamento (por exemplo, sincronização na cloud ou contas de utilizador), esta política será atualizada antes dessa funcionalidade ser lançada.
